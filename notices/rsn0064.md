## Overview

Beginning with RAPIDS v26.12, container images will only support the latest-supported Python version from that RAPIDS release's development cycle.

```text
# before
rapidsai/notebooks:26.12-cuda12-py3.12
rapidsai/notebooks:26.12-cuda12-py3.13
rapidsai/notebooks:26.12-cuda12-py3.14
rapidsai/notebooks:26.12-cuda13-py3.12
rapidsai/notebooks:26.10-cuda13-py3.13
rapidsai/notebooks:26.12-cuda13-py3.14

# after
rapidsai/notebooks:26.12-cuda12
rapidsai/notebooks:26.12-cuda13
```

For the full list of available tags for the affected images, see:

* https://hub.docker.com/r/rapidsai/base/tags
* https://hub.docker.com/r/rapidsai/cuvs-bench/tags
* https://hub.docker.com/r/rapidsai/cuvs-bench-cpu/tags
* https://hub.docker.com/r/rapidsai/notebooks/tags

## Impact

Users should plan to update the tags they used to reference these images when updating to RAPIDS 26.12 or later.

Users requiring other Python versions should plan to interactively update their environments or build their own images,
e.g. like this:

```dockerfile
FROM rapidsai/notebooks:26.12-cuda13

# downgrade to Python 3.13
RUN conda install --yes --name rapids python=3.13
```

To see the Python versions RAPIDS support, visit https://docs.nvidia.com/datascience/install/
