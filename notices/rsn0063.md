## Overview

RAPIDS is dropping support for Python 3.11 in the upcoming release of v26.12, scheduled for December 10, 2026.
v26.12 will support Python 3.12, 3.13, 3.14, and 3.15.

## Impact

Users should plan to move to a supported Python version (3.12 or newer) as soon as possible.
