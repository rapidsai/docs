## Overview

NVIDIA CUDA-X Libraries for Data Science (formerly RAPIDSAI) will stop publishing `nx-cuGraph` packages after Release v26.12. Development for the `nx-cuGraph` repository will be paused, no new packages will be published, and the repository will be archived with migration guidance. 
`nx-cuGraph` helped users GPU accelerate their `networkX` based graph analytics easily by adding a single line of code to import its extensions.


## Impact

`nx-cuGraph` v26.12 will be the final release. No new `nx-cuGraph` conda or pip packages will be published after v26.12.

## Migration guidance

There will not be a direct successor package that re-implements the `cuxfilter`
API. New work should use the skill replacement and direct-library patterns:

There will not be a direct successor package that re-implements the `nx-cuGraph` capabilities. New work should use the skill replacement and direct-library patterns.  For existing workloads, users can pin to the final release, `nx-cugraph=26.12` or migrate their workloads to `cuGraph`.

## Continued GPU accelerated graph analytics support

NVIDIA CUDA-X for Data Science continues to support GPU-accelerated graph analytics through projects such as `cuGraph`, `Kumo`, and their related libraries.
